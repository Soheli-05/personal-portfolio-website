# Personal Portfolio Website

A responsive personal portfolio website showcasing my technical skills, projects, and professional profile. Designed to present my work, experience, and interests in software development and technology.

## 🚀 Live Demo

**[Visit My Portfolio](https://soheli-portfolio.vercel.app/)**

## 📌 About the Project

This portfolio website serves as my personal space on the web to highlight my technical background, development skills, and projects.

It features a clean and user-friendly interface, responsive layouts, and structured sections to help visitors explore my work and connect with me.

## ✨ Features

- **Responsive Design:** Optimized for desktop, tablet, and mobile devices.
- **About Section:** Introduction and professional background.
- **Skills Section:** Overview of technical skills and technologies.
- **Projects Showcase:** Highlights selected development and machine learning projects.
- **Contact Section:** Provides ways to connect with me.
- **User-Friendly Interface:** Clean layout and easy navigation.
- **Performance Focus:** Designed with attention to loading speed and usability.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## 💻 Run Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/Soheli-05/personal-portfolio-website.git
   ```

2. Navigate to the project directory:

   ```bash
   cd personal-portfolio-website
   ```

3. Open `index.html` in your browser, or use the Live Server extension in VS Code.

## 🎯 Project Objective

The objective of this project is to build a professional online portfolio while applying frontend development concepts, responsive web design, UI/UX principles, and web performance practices.
